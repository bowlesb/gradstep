## 2. New problems

1. **iPhone Settings rows run edge to edge** (regression; `iphone-light/settings.png`, `iphone-dark/settings.png`). Setting `.contentMargins(.horizontal, …0…)` (RootView L771) removes the normal inset-card margins on iPhone. Apply that modifier only on iPad; on iPhone leave the system default.

2. **iPad column edges don't line up** (`ipad-light/library.png`, `chat-conversation.png`, `chat-credits.png`). The Library header's content is 752 pt (`.frame(maxWidth: column + 2*margin).padding(…)`, L332), the chat header, banner and message box are 720 pt (`.frame(maxWidth: column).padding(…)`, L600/629/660), and the list and messages are 688 pt.
   - Add one `readableColumn()` modifier to DesignSystem.swift: `.padding(.horizontal, margin).frame(maxWidth: column).frame(maxWidth: .infinity)`.
   - Use it in all of those places.

3. **Table mode: header and banner widths differ** (`ipad-*-landscape/library-table.png`). The search header is held to the column while the "Sign in to sync" banner and the table run full width. When the table is showing, let the header run full width too.

4. **Menus are still system blue and don't show current choices** (`library-options.png`, `paper-options.png`). Two fixes:
   - **Icons:** draw menu icons with `UIImage(systemName:)?.withTintColor(accent, renderingMode: .alwaysOriginal)` through a small helper.
   - **Current choice:** wrap each inline picker in a `Menu` whose label has a second `Text` holding the current choice ("List", "Recent"); the second `Text` shows as a subtitle.

5. **All chats rows are accent-coloured** (`iphone-*/chat-history.png`). Inside a Button, `.primary` and `.secondary` take the accent colour. Add `.tint(.primary)` to the row Button (RootView about L853), as `openRow` already does.

6. **"Done" looks different from sheet to sheet.** Use `.confirmationAction` in PaperView L146 and L162, DiagramView L15, CreditsStoreView L49, ReportsView L29 and LibraryChangesView L65. In Add paper, move the confirm action to a `.confirmationAction` "Add" button.

7. **The two Library layouts disagree on topics and text** (`library-metadata-list.png` vs `library-table.png`).
   - **Metadata colour:** the list's metadata line is too faint at `.tertiary`; change it to `.secondary`.
   - **Topic names:** the list shows raw codes ("cs.LG · stat.ML") while detailed rows show "Machine learning, Statistical ML". Use the readable names in `PaperRow`.
   - **Status text:** "Converting equations and figures…" in the list vs "Converting…" in detailed rows; pick one.

8. **Device-setup dead end, worded two ways.**
   - **Store** (`store.png`): "Finish setting up this device" has no button. Add one prominent action that opens the recovery sheet.
   - **Add paper** (`library-add.png`): over a signed-out Library, the sheet says "Restore this device to save library changes." Use one wording and the same action as the store. If the user is signed out, show Sign in instead.

9. **Chat pane in the iPad Reader layout** (`ipad-light-landscape/paper.png`): the title is cut to "Understanding a…", and the paper link repeats the paper shown right beside it. Hide the paper link when `wideMode == .reader`.

10. **Small leftovers.**
    - **Chat toolbar:** add a fixed `ToolbarSpacer` between compose and "…" so they match Library's separate circles (iOS 26 only).
    - **Hide-keyboard button:** show it only on iPhone.
    - **Open paper in the table:** stop colouring its title in Library mode (LibraryTableView L58).
